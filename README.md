# CoDoc – Collaborative Markdown Editor

CoDoc is a real-time collaborative Markdown editor inspired by Google Docs.

Multiple users can edit the same document simultaneously and see
changes without refreshing the browser.

## Objectives

- Develop a collaborative Markdown editor.
- Support real-time document synchronization.
- Demonstrate collaborative software development using Git and GitHub.
- Store documents and version history using PostgreSQL.

## Technologies

- Next.js
- React
- TypeScript
- PostgreSQL
- Prisma
- Socket.IO
- Bun

## Main Features

1. Real-time collaborative editing.
2. Live cursors and user presence.
3. Operational Transformation synchronization.
4. Markdown editing and preview.
5. Document version history.
